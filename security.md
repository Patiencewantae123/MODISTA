# 🔒 Security Policy

The following versions of **Modista Fashion App** are currently supported with security updates:

| Version | Supported          |
|---------|--------------------|
| 1.x     | ✅ Fully supported |
| 0.x     | ❌ Not supported   |

Please update to the latest version to ensure you receive critical security updates.

---

## 🛡️ Reporting a Vulnerability

If you discover a security vulnerability in **Modista Fashion App**, we appreciate your responsible disclosure. Please follow these steps to report it:

1. **Do Not Publicly Disclose**: Avoid sharing details of the vulnerability publicly until it has been addressed.
2. **Email Us**: Report the vulnerability to us via email:
   - **Email**: [security@modista.com](mailto:security@modista.com)
   - Use "Security Issue: [Brief Description]" in the subject line.
3. **Include Details**: Provide the following information in your report:
   - **Description**: A clear and concise description of the vulnerability.
   - **Steps to Reproduce**: Detailed steps or code snippets that demonstrate the issue.
   - **Impact**: A summary of the potential impact of the vulnerability.
   - **Environment**: Information about the environment where the issue was found (e.g., OS, browser, app version).
4. **Request for Follow-Up**: If needed, specify if you'd like updates on the status of the fix.

---

## 🛠️ Fixing Vulnerabilities

Once we receive your report:
1. We will acknowledge receipt of your email within **48 hours**.
2. Our team will investigate and validate the issue.
3. After validation, we will:
   - Develop a fix.
   - Communicate with you to clarify details if necessary.
   - Credit you for your responsible disclosure, if you wish.

---

## ⏳ Disclosure Timeline

We are committed to addressing reported vulnerabilities promptly:
- A fix will be developed and deployed within **30 days** (or sooner for critical issues).
- You will be notified once the fix is live.

We take security seriously. To ensure the safety of our app and user data:
